# 星域契约：裂隙纪元

## 一、项目定位

这是一个大型单机魔幻异兽养成 RPG，核心玩法以“探索、捕捉、养成、战斗、剧情推进”为闭环，整体风格兼顾宝可梦式收集乐趣与更深的剧情与世界观表达。

游戏目标不是单纯复制经典玩法，而是做出明确差异：
- 不是“谁的数值更高”，而是“谁能读懂场域、生态和时序”
- 不是“收集宠物”，而是“建立契约、共同成长、共享命运”
- 不是“打怪升级”，而是“走入世界，改变世界”

核心卖点：
- 生态战斗：每种异兽都有生态位、环境偏好、相克关系与群落协同
- 域印系统：天气、时间、地形、区域属性会显著影响战斗和异兽表现
- 同伴共鸣：异兽与主角关系深度决定技能、剧情转换和最终进化路线
- 真实世界观：每个地区都具有政治、宗教、矿产、灾害与传说背景

---

## 二、核心设计哲学

### 1. 玩法的深度来自“世界规则”，不是堆叠数值

本作的战斗系统强调：
- 区域与环境的战略价值
- 异兽之间的生态互动
- 主角与伙伴的情感铺垫和共鸣能力
- 角色编队与队伍节奏管理，而不是纯数字爆发

### 2. 角色成长不是抽卡，而是“命运选择”

玩家的成长路线会受到以下因素塑造：
- 训练路线：战斗型 / 保护型 / 斥候型 / 先导型
- 人际关系：伙伴、师长、敌人、盟友、宗教组织
- 地域选择：在不同文明与阵营中塑造自己的身份
- 进化路径：同一种异兽可走不同进化路线，拥有不同技能和外观演化

### 3. 探索、战斗、剧情并不是并列模块，而是一体化循环

探索世界会发现答案；答案会改变你的队伍和路线；队伍和路线又会决定你如何面对最终危机。

---

## 三、游戏名称与IP定位

游戏名：星域契约：裂隙纪元

IP定位：
- 前台：轻松易懂、可爱、可收藏、强代入
- 中台：野外探索、异兽养成、剧情推进、策略战斗
- 后台：充足拓展空间，可持续推出地域扩展、剧情 DLC、隐藏内容、Boss 挑战

风格定位：
- 现代奇幻 + 生物生态 + 以地域为中心的开放探索
- 视觉语言：明亮、富有生机，但有代入感与神秘压迫感

## 四、世界观：裂隙星图

### 1. 宇宙背景

世界并非传统意义上的“单一大陆”，而是由多个漂浮的“星域岛屿”拼成的星域地图。每一块岛屿都有自己的地质、生态和文明。

这些星域在数千年前曾被“裂隙之潮”撕裂，形成了大量低位空间口和异常生物群落。世界的秩序依靠“域印”维持：
- 域印：用于稳定地脉、保护生物群落、限制混乱裂隙
- 但域印正在失衡
- 主角成为“契约使”，肩负修复裂隙、保护全世界的职责

### 2. 七大地域

1. 晨曦高原
   - 太阳初升地带，适合初期训练生涯
   - 温和文明、骑士团、古旧遗迹
   - 主要异兽：木系、光系、飞行系

2. 灼棘荒原
   - 热风、火山、废墟与风暴
   - 一个强者崛起和旧王国衰退的区域
   - 主要异兽：火系、岩系、毒系

3. 黯霜海湾
   - 冷海、冰原、鲨潮与海盗文明
   - 叙事重心：海岛神话与失落海王国
   - 主要异兽：水系、冰系、雷系

4. 迷离白林
   - 神秘森林、古树与灵气浓缩地
   - 适合支线探索、隐藏精灵和灵兽契约剧情
   - 主要异兽：草系、幻系、精神系

5. 断裂矿脉
   - 地下重力异常，机械遗迹与古矿工文明
   - 从前的伪神与机器文明冲突
   - 主要异兽：钢系、地系、雷系

6. 孤星禁地
   - 被裂隙吞没的高危区域
   - 只在核心剧情中开放
   - 主要异兽：暗系、混沌系、时空系

7. 苍穹圣城
   - 世界制衡中心，域印核心和最终决战地
   - 主角最终身份的揭示场

## 五、剧情概念

### 主线：裂隙纪元

主人公是被卷入“域印失衡事件”的训练师，加入“星穹署”或类似前线组织。随着旅行推进，玩家逐步发现：
- 世界的裂隙不是偶然产生的
- 某个文明早已掌握“稳定域印”的技术
- 一部分人希望继续维持旧秩序，而另一部分希望让世界自由演化

主角不是“救世主模板”，而是“选择者”。

### 角色分线

- 领路导师：资深域印使，温和但严厉，象征“守序”与“经验”
- 研究者：智者型角色，揭示世界历史和异兽生态之谜
- 叛逆骑士：曾经参与过崩裂事件，追寻真相与赎罪
- 夺权者：想用“绝对秩序”控制异兽和域印
- 地域守护者：每个区域的头目，形成不同任务路线

### 结局分支

1. 维持秩序：稳定世界，但牺牲很多自由与生态变化
2. 让世界自然成长：放任裂隙和生态演化，世界充满不确定性
3. 共同重建：打破旧秩序，重新构建基于异兽与人类共存的世界

## 六、异兽设计系统

### 1. 异兽基本构成

每种异兽由 5 个层级构成：
- 形态：外观、体型、角/羽/鳞/器官设计
- 生态：食物来源、天敌、环境适应性
- 元素：火/水/木/光/暗/雷/土/冰等
- 能力：攻击、防御、支援、控制、特殊技能
- 契约：与训练者关系、角色性格、性格成长方向

### 2. 创新：生态位与阵型斗争

异兽不只看单项数值，而是看其在组队中的生态位：
- 先锋：前排承压
- 先导：速度与先制
- 支援：恢复/BUFF/控制
- 斥候：侦查/环境操控
- 终结者：爆发型输出

不同异兽组合会带来“群落效应”，如：
- 防御型异兽与支援异兽相乘形成坚固阵线
- 先导异兽与环境操控异兽可形成“强制先制阵”
- 进化后可能从输出转向控制，造成不同战斗节奏

### 3. 样例异兽

#### 1）烬叶鹿
- 类型：木系 / 先导
- 特征：头部有火焰纹路，走路时草发出轻响
- 技能：明叶斩、火芽冲、林间护盾
- 设计理念：温和但强势，适合新手玩家快速上手

#### 2）断潮鲛
- 类型：水系 / 斥候
- 特征：背部鳍片像海浪刀刃
- 技能：潮汐分裂、深海掠取、海浪屏障
- 设计理念：适合控制流与推进战斗

#### 3）熔岩犀
- 类型：火系 / 先锋
- 特征：结实而高大，肩背有熔化纹理
- 技能：烈焰冲撞、熔浆护甲、地塌
- 设计理念：推进型 Boss 级战力

#### 4）镜月狐
- 类型：幻系 / 术法
- 特征：尾巴像半月形月牙，步伐轻盈
- 技能：镜影分身、月华禁术、无声步
- 设计理念：在战斗中模拟“信息差”和“策略差”

#### 5）幽冥蝠王
- 类型：暗系 / 终结者
- 特征：翼膜带裂隙纹路
- 特技：噬梦、裂隙坠落、暗夜追击
- 设计理念：高爆发，适合剧情 Boss 设计

## 七、战斗系统设计

### 1. 基础机制

- 角色和异兽都拥有 4 个核心属性：力量、速度、防御、灵性
- 每回合可执行：攻击、技能、道具、换队、守护、融合技能
- 先手由速度、地形、天气、状态变化共同决定
- 角色和异兽都能获得“共鸣值”，达到一定上限后发动强力合体技

### 2. 域印系统（核心创新）

每个区域具有“域印属性”，例如：
- 晨曦：光明 / 生长
- 灼棘：火焰 / 荒芜
- 黯霜：潮汐 / 冰封
- 迷离白林：生命 / 幻境
- 断裂矿脉：重力 / 机械

战斗中发生以下变化：
- 若使用与场地属性相同的攻击，威力提升
- 若属性相克，则强度大幅变化
- 某些异兽会在特定天气/地形下触发“觉醒状态”
- 场地造成持续伤害、增益或状态异常

这使得战斗远离“单纯属性克制”而进一步回归策略思维。

### 3. 队伍机制

- 玩家最多 6 名异兽组成队伍，实际战斗中可派出 3 名
- 每种异兽必须承担“位置角色”，不能只看强度堆叠
- 建议设置一个“队列互补”原则：输出、控制、治疗、坦克、支援、先导

### 4. 合体技与共鸣系统

当主角与异兽的“契约等级”达到阈值时，可发动：
- 共鸣斩：主角与异兽同步攻击
- 领域融合：以场地属性为核心，释放大范围技能
- 觉醒奥义：极限状态下大幅强化威力和控制能力

### 5. 训练与成长线路

- 每只异兽可有 2-3 种成长路线
- 达到关键等级后可解锁高级技能树：攻击型 / 防御型 / 巡逻型 / 支援型
- 带来差异化“最终体型”与“战斗特征”

## 八、UI 与交互设计

### 1. 主菜单

- 启动动画：星图与裂隙流动型背景
- 选项：开始游戏 / 继续 / 设置 / 成就 / 资料库
- 设计风格：柔和的金属感、深蓝与星辉色板、清晰的层次与极少 clutter

### 2. 世界地图

- 3D 或 2.5D 地图视角
- 区域背景颜色明显区分，方便快捷导航
- 无需大量表格显示，优先突出旅行路径、任务提示和危险等级

### 3. 战斗界面

- 左侧：队伍信息、HP/MP/状态
- 中间：异兽与敌方信息
- 右侧：技能列表、道具、任务提示、战斗记录
- 使用清晰的颜色区分属性、状态与强弱关系

### 4. 角色界面

- 异兽图鉴：各异兽详情、生态信息、契约状态、进化路线
- 队伍编排：按位置、战略职责、生态位展示
- 契约记录：玩家与异兽关系视图

### 5. 美术方向

- 画风偏向“高质感大气、细致可爱”
- 强调异兽立体轮廓和角色神情表达
- 战斗 UI 采用“透明浮层 + 小清晰标签”而非拥挤的游戏菜单

## 九、内容节奏与开发路线

### 早期（1-2 个月）
- 世界观、异兽类型、地图区域草案
- 玩家原型：移动、探索、随机遭遇、战斗选项

- 加上更多地图、支线、最终区域和结局路线
- 攻克复杂战斗难度、精英 Boss 和隐藏挑战

### 终期（9-12 个月）
- 完整世界观、结局分支、成就系统、剩余隐藏内容
- 可进入稳定测试与整体验收集阶段

## 十一、核心闭环：最重要的玩法节奏

1. 玩家在野外探索，遇到稀有异兽
2. 通过战斗、捕捉、交流建立契约
3. 异兽成长并解锁新技能 / 进化路线
4. 返回城镇与 NPC 互动推进剧情和任务
5. 选择区域路线，挑战更强 Boss
6. 在剧情进展中理解世界规则，并最终做出世界选择

这是本作最重要的核心循环：
探索 → 发现 → 契约 → 成长 → 决策 → 改变世界

---

## 十二、最终结论

这款游戏的重点，不是把宝可梦式玩法的每个系统“机械抄一遍”，而是把“收集、成长、回合战斗、世界探索、剧情抉择”重新组合成一个符合我们设计理念的原创IP。

在保持可理解性与舒适体验的前提下，我们的创新方向是：
- 生态系统替代单纯属性值
- 区域与环境战斗替代单纯裸数值
- 伙伴关系和共鸣替代无感强度提升
- 世界观、地区差异与结局分支替代重复模板

这会让本作在市场上更有辨识度，也更有可能形成持续的内容扩展价值。
