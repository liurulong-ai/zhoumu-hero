# 星域契约：裂隙纪元 · 角色与异兽卡设计

## 一、主角设定：林岚

### 基本信息
- 名称：林岚
- 年龄：17
- 身份：星穹署见习契约使
- 口号：我不是来征服世界的，我是来让它重新呼吸。

### 角色定位
林岚来自晨曦高原，曾在一场裂隙事故中亲眼看见母亲在域印失衡时牺牲。她性格温和但坚定，重视同伴与生态平衡，习惯用协商和理解代替强制取胜。

### 关键特征
- 不喜欢直接使用暴力解决问题
- 对裂隙与生物命运有强烈执念
- 愿意为弱者和未被理解的异兽发声
- 逐渐成长为“真正的契约者”，而不是“只是强者”

### 角色成长线
- 初期：不信任过度秩序与强权
- 中期：逐步理解世界复杂性
- 后期：必须在秩序与自由之间做出决定

### 战斗风格
- 以协同攻击和对场地理解为主
- 更擅长建立“生态优势”而不是硬碰硬
- 最终可使用“星穹立场”技能，让全队获得地形适应与命运共鸣

## 二、核心同伴角色

### 1. 祁霏：星穹署研究者
- 职业：域印学研究员
- 性格：理性、冷静、细致
- 角色功能：解释世界观、揭示异兽能力与裂隙原理
- 关键冲突：她相信数据和规律，但逐渐认识到人无法完全逻辑化生命

### 2. 桓澜：叛逆骑士
- 职业：前域守骑士
- 性格：强硬、愤怒、内敛
- 角色功能：提供前线战力和反叛精神
- 关键冲突：曾背叛过组织，内心仍在自责

### 3. 素筠：远航祭司
- 职业：海湾祭司兼航海向导
- 性格：温柔、敏感、有启迪性
- 角色功能：帮助主角理解自然界与契约之道
- 关键冲突：她早已知晓世界命运与“大海将吞没旧秩序”

---

## 三、主要反派与敌对阵营

### 1. 归墟议会
- 目标：通过“绝对秩序”稳定裂隙，关闭自由生态系统
- 价值观：秩序高于生命与自由
- 代表人物：审判长祈昏

### 2. 朽月教团
- 目标：借裂隙之力获取永生与神权
- 价值观：扭曲的“净化”与“牺牲”哲学
- 代表人物：月裂祭司曲真

### 3. 末日猎手团
- 目标：猎杀异兽并抢夺其核心核芯
- 价值观：以强者为王、以资源为一切
- 代表人物：猎风王璟弩

## 四、核心异兽一览表

### 1. 烬叶鹿（木系 / 先导）
- 设计定位：新手友好主力
- 外观：四足草兽，额角长出带火纹的叶状角
- 能力：明叶斩、火芽冲、林间护盾
- 角色定位：适合引导玩家理解生态协同和先导体系
- 进化路线：踏春鹿 → 暮火鹿王

### 2. 断潮鲛（水系 / 斥候）
- 设计定位：控制与推进型
- 外观：巨鳍、流线型身体，背部有潮纹刀片
- 能力：潮汐分裂、深海掠取、海浪屏障
- 角色定位：擅长断开敌方节奏，适合打乱空战节奏
- 进化路线：裂潮鲛 → 绝潮海王

### 3. 熔岩犀（火系 / 先锋）
- 设计定位：前排强攻型
- 外观：厚甲、熔纹皮肤、两角像火山口
- 能力：烈焰冲撞、熔浆护甲、地塌
- 角色定位：高爆发高承压，适合突破防守型敌人
- 进化路线：熔骨犀 → 灼裂山魁

### 4. 镜月狐（幻系 / 术法）
- 设计定位：策略型输出
- 外观：银白尾巴，肩背出现半月型纹路
- 能力：镜影分身、月华禁术、无声步
- 角色定位：擅长制造虚假位置和对敌方核心造成致命干扰
- 进化路线：月影狐 → 镜幽月灵

### 5. 幽冥蝠王（暗系 / 终结者）
- 设计定位：Boss 级爆发
- 外观：翼膜裂隙纹理，眼中有冷冽星空色
- 能力：噬梦、裂隙坠落、暗夜追击
- 角色定位：在对局中制造巨大威胁，常出现于后期剧情与试炼
- 进化路线：噬梦蝠 → 幽冥蝠王 → 裂隙王座

### 6. 晶脉麒麟（光系 / 支援）
- 设计定位：圣战与恢复型
- 外观：前额有光晶冠，四蹄发光
- 能力：星辉癒纹、光域护罩、天穹引导
- 角色定位：管理队伍节奏，支撑“天命”路线
- 进化路线：晨光麒麟 → 星穹圣麒麟

### 7. 岩脊蜥（地系 / 守护）
- 设计定位：中期重装前排
- 外观：背壳与岩壁相嵌
- 能力：岩墙、裂地冲刺、护盾脊
- 角色定位：强硬、稳定、适合教学流程中的防守训练
- 进化路线：岩脊蜥 → 固土巨蜥

### 8. 霜篷鹭（冰系 / 先导）
- 设计定位：区域 Boss 及支线能力
- 外观：羽毛呈霜白色，双翼带蓝光
- 能力：冰风剪、寒潮引导、霜域锁
- 角色定位：擅长压制速度型和射程型敌人
- 进化路线：霜篷鹭 → 极寒雪王

## 五、异兽深度设计原则

### 1. 每个异兽都要有“情感纹理”

不仅是战斗角色，还需要有：
- 喜好
- 恐惧
- 对环境的依恋
- 与主角建立契约后的成长感

比如：
- 烬叶鹿最初会对火焰退缩，只有在主角保护下才愿意靠近火焰
- 断潮鲛害怕自己失控时吞没同伴
- 镜月狐追求“看清本质”的过程，会在主角与秩序立场之间摇摆

### 2. 进化不能只是换皮

进化应该带来：
- 新技能
- 新外观
- 新战术价值
- 新剧情关联

### 3. 生态位决定成败

不同异兽的战术价值来自：
- 能否打断敌人节奏
- 能否在特定域印中增强队伍表现
- 是否能够解决关卡的特有难题

## 六、战斗中的新角色定位方案

### 队伍编制原则
- 1 先锋：承受前排压力
- 1 先导：推进节奏
- 1 支援：恢复与控制
- 1 斥候：环境与效果干扰
- 1 终结者：关键爆发

### 样例队伍配置
- 烬叶鹿（先导）
- 熔岩犀（先锋）
- 断潮鲛（斥候）
- 晶脉麒麟（支援）
- 镜月狐（终结者）

---

## 七、最核心的“主角之命运”

林岚最终不只是一个收集异兽的人，而是要面对：
- 裂隙为何形成
- 域印究竟是保护世界，还是牢笼
- 真正的自由，是允许世界变化，还是强制保存秩序

她必须在世界与异兽之间找到属于自己的答案——也正是这套世界观与同伴关系，使故事不只是“打败强敌”，而是“理解命运”。
